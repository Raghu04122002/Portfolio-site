# Raghavender Reddy Sudireddy — The Systems Edition

A custom editorial portfolio built with Next.js App Router, React, TypeScript, Tailwind CSS, Motion, and Lucide.

## Run

```bash
npm install
npm run dev
```

Visit http://localhost:3000. For production, run `npm run build && npm start`.

## Features

- Responsive editorial layout with dark/light visual modes
- Animated hero system diagram and accessible reduced-motion support
- Swipeable/drag-scroll project rail with interactive engineering notes
- Expandable experience timeline and interactive skills clusters
- Contact email, copy action, resume download, SEO metadata
- All project information derived from supplied resumes
